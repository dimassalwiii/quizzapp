# 🧠 Kuis Interaktif — Interactive Quiz App

Aplikasi kuis interaktif berbasis web yang menampilkan soal-soal dari berbagai tema: Bahasa Indonesia, Pengetahuan Umum, dan Teknologi & Coding.

---

## 📋 Deskripsi Proyek

**Kuis Interaktif** adalah aplikasi web sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript murni (tanpa framework). Aplikasi ini menampilkan 10 soal pilihan ganda secara acak dengan timer per soal, feedback langsung, dan skor akhir.

Proyek ini dibuat sebagai bagian dari **Tugas Praktik 06** mata kuliah Bahasa Indonesia — untuk mendemonstrasikan kemampuan membuat proyek coding sederhana dan mendokumentasikannya secara profesional.

---

## ✨ Fitur

- 10 soal pilihan ganda dari berbagai tema
- Timer 15 detik per soal
- Soal diacak setiap kali kuis diulang
- Feedback dan penjelasan jawaban langsung setelah memilih
- Progress bar untuk memantau kemajuan
- Skor akhir dengan komentar motivasi
- Tombol ulangi kuis tanpa reload halaman
- Desain responsif dan bersih

---

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|-----------|----------|
| HTML5 | Struktur halaman web |
| CSS3 | Tampilan dan animasi |
| JavaScript (Vanilla) | Logika kuis, timer, dan interaksi |

Tidak menggunakan library atau framework eksternal — murni HTML, CSS, dan JS.

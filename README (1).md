## 🚀 Cara Instalasi

1. **Clone repositori ini:**

```bash
git clone https://github.com/username/quiz-app.git
```

2. **Masuk ke direktori proyek:**

```bash
cd quiz-app
```

3. **Buka file utama di browser:**

```bash
# Langsung buka dengan browser
open index.html

# Atau gunakan Live Server (VS Code Extension)
```

> Tidak diperlukan instalasi dependensi tambahan. Cukup buka file HTML di browser mana pun.

---

## 📖 Cara Penggunaan

1. Buka aplikasi di browser
2. Klik tombol **"Mulai Quiz"** untuk memulai
3. Baca setiap pertanyaan dan pilih salah satu jawaban
4. Klik **"Next"** untuk lanjut ke soal berikutnya
5. Setelah semua soal selesai, skor akhir akan ditampilkan
6. Klik **"Ulangi Quiz"** untuk mencoba lagi
